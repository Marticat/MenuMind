# Mise en Place — L’Atelier Gastronomique

React-студия ресторанных описаний по трём SVG-макетам из корня проекта и дизайн-системе Old Money. React 19, TypeScript, Vite, Lucide. Шрифты Cormorant Garamond, Inter и JetBrains Mono поставляются локально; фотография извлечена из предоставленного SVG.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
cd frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Для готовой сборки:

```sh
npm run build
npm run preview
```

## Экраны и возможности

- `/#studio` — техкарта, три стиля повествования, демонстрационная генерация для четырёх каналов, редактура, копирование и экспорт JSON.
- `/#channels` — адаптеры каналов, редактирование лимитов, настройки тона.
- `/#brand` — эталонные тексты и регуляторы голоса бренда.
- `/#docs` — проект API-контракта, примеры запросов на четырёх языках и скачивание описания API.
- `/#library` — поиск, фильтры, добавление и редактирование блюд.

Ctrl+Enter / Cmd+Enter запускает генерацию в студии. Сначала сохраните профиль ресторана, затем сгенерируйте новые описания для применения изменённых лимитов и регуляторов.

## Границы текущей версии

Это работающий frontend с локальным шаблонным движком, а не подключённая LLM. Данные сохраняются в localStorage текущего браузера. Кнопка подготовки публикации скачивает пакет JSON; она не отправляет его во внешние сервисы. Печатный вариант находится в экспортируемом пакете.

Backend, реальная авторизация, multi-tenant RLS, очереди, embeddings/RAG, API-ключи, webhooks и POS-интеграции не реализованы. Лимиты каналов взяты из предоставленного брифа. Эталонные тексты сохраняются как референсы, но не используются для векторного поиска. Три регулятора меняют правила локального шаблона, а не параметры модели.

Описание API — будущий контракт. Примеры предполагают серверное окружение с `MISE_API_URL` и `MISE_API_KEY`; секреты нельзя передавать в клиентскую сборку. Аллергены и другие свойства блюд требуют проверки ресторана.

## Проверки

```sh
npm run build
npm test
npm run format:check
```

Playwright использует установленный Chrome на Windows. В других окружениях предварительно выполните `npx playwright install chromium`. Тесты проверяют создание и редактирование блюд, лимиты каналов, сохранение после перезагрузки, копирование, выгрузку и адаптивность на 1440, 390 и 320 px. Скриншоты сохраняются в `.cache/`.

## Структура

- `src/App.tsx` — экраны и интерактивные компоненты.
- `src/model.ts` — типы данных, демонстрационный движок, экспорт и хранилище.
- `src/styles.css` — дизайн-токены, оформление и адаптивные состояния.
- `public/dish.jpg` — исходная фотография блюда из SVG.
- `tests/studio.spec.ts` — браузерные сценарии.

Все команды после `cd frontend` выполняются из папки `frontend`. Исходные SVG и PDF оставлены в корне проекта без изменений, на уровень выше. Настройки IDE и файлы backend размещаются отдельно от frontend.
