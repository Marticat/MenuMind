# Живая проверка LLM — 6 октября 2026

Откройте **[выполненный Notebook](MenuMind_LLM_evaluation.ipynb)** или
**[HTML-версию](MenuMind_LLM_evaluation.html)**. Notebook содержит входы и результаты
и повторно выполняется без API-ключа. Здесь отдельный эксперимент генерации RU/KK;
он не заменяет прежнее исследование Epicurious в соседней папке рабочего пространства.

## Что измерено

80 настоящих вызовов `gpt-5.6-luna` через `api.openai.com`, всего **33 433 токена**:
23 079 входных и 10 354 выходных. Из них 64 первичных сравнительных запроса,
8 перегенераций, 1 smoke, 3 браузерных и 4 дополнительных API-проверки.
Отклонённые сервером ответы включены в журнал и расход. Ошибки инфраструктуры
проверены отдельно локальным fault injection; это не ответы модели.

| Итоговая выборка | Простой промпт | Подробный промпт |
| --- | ---: | ---: |
| Принято сервером | 11/16 | 16/16 |
| Среднее время | 2,553 с | 1,902 с |
| Максимальное время | 4,426 с | 4,648 с |
| Средний расход токенов | 300,9 | 460,1 |

Это прохождение ограниченного серверного валидатора, **не доля фактически точных
описаний**. Качественная проверка Codex обнаружила неподтверждённые формулировки
даже у подробного промпта: «лёгкий», количество соли и последовательность готовки.
Независимая редакторская оценка и проверка носителем казахского не проводились.

Оба языка, перевод RU→KK, лимиты 250/60 и ошибки недоступности проверены. Все
измеренные вызовы уложились в 10 секунд, но нагрузочный SLA этим не доказан.
Перегенерация изменила текст в **6 из 8** попыток; два повторных KK-ответа
отклонены. Различимость трёх тонов не подтверждена: тексты часто одинаково нейтральны.

## Доказательство работы сайта

`results/browser.json` содержит три успешных живых запроса через собранный сайт:
RU, повтор RU и KK. Проверено совпадение ответа провайдера, ответа API и видимого
текста карточки. Сохранены request ID, response ID, токены и скриншоты.
Никакого Playwright-перехвата, возвращающего готовый текст, в этой проверке нет.

Первый запуск затем остановился на неверном **селекторе теста ошибки** (`alert`
вместо `status`); исходный отчёт не переписан. Исправленная проверка ошибок
записана в `results/browser-faults.json`: оба сценария прошли, шаблонная подмена
и новая запись генерации отсутствуют. `results/contract.json` — дополнительные
проверки ограничения 60 символов, перевода и тонов.

## Состав материалов

- `inputs.json`: 32 авторских примера, 16 блюд, RU/KK; только указанные поля считаются фактами.
- `results/dev.jsonl`, `final.jsonl`: вход, полный промпт, сырой ответ, результат проверки, время, usage.
- `results/freeze.json`: решение и хеши, записанные до запуска итоговой выборки.
- `results/frozen-sources.json`: точный снимок проверенного кода, до последующего форматирования.
- `results/qualitative_review.csv`: проверка смысла с хешами ответов; автор — Codex, не человек.
- `analysis/`: очищенные входы, аудит, разделение выборок, таблицы и 8 графиков.
- `analysis/metrics.json`: итоговые численные результаты.
- `analysis/portable_verification.json`: проверка самостоятельного запуска Notebook.

Все переводы одного блюда остаются в одной части. 8 блюд отведены для разработки,
8 — для финальной проверки. Промпты между частями не менялись. Перегенерации
не входят в основное сравнение. Случайные неудачи не перезапускались и не удалялись.

## Повторить анализ

В Jupyter: Restart Kernel → Run All. Или из корня приложения:

```sh
python -m pip install -r experiments/llm/requirements.txt
python experiments/llm/execute_notebook.py
python experiments/llm/check_portable.py
```

Для нового живого эксперимента сохраните `results` под другим именем, настройте
`.env`, затем выполните `run.mjs smoke`, `run.mjs dev`, `freeze.py`, `run.mjs final`,
`npm run build`, `browser.mjs`, `browser.mjs --faults-only`, `contract.mjs`.
JS-файлы запускаются через `node experiments/llm/…`, Python — через
`python experiments/llm/…`. Это новые платные запросы; ответ и задержка могут измениться.
Для новых ответов нужна новая качественная разметка. `review.py` содержит оценку
именно текущего прогона и отказывается применять её к другим файлам.

Секреты и Authorization не сохраняются. Модель не переобучалась; эксперимент
сравнивает инструкции. Известные ограничения валидатора и неудовлетворённые пункты
ТЗ подробно разобраны в Notebook.
