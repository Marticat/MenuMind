| --- | ---: | ---: |
| Принято с первой попытки | 16/16 | 0/16 |

| Среднее время логического запроса | 2,14 с | 4,43 с |

Один запрос возвращает четыре канала и вариант. В цену и время включены все
попытки, в том числе отклонённые. Цена перегенерации — около $0,312/1 000.
Тариф модели проверен 07.10.2026 по
[официальной странице](https://developers.openai.com/api/docs/models/gpt-5.6-luna).
Хостинг, налоги и индивидуальный тариф не включены.

Все 16 перегенераций изменили четыре канала (две потребовали исправления).
Три тона дали разные формулировки одного блюда на RU/KK. Браузер подтвердил
совпадение ответа провайдера, API и видимой карточки. Ошибки HTTP 503 и таймаута
показаны пользователю без шаблонной подмены.

**Ограничения не скрыты:** один подробный ответ добавил неподтверждённое «в бистро»;
при дополнительном лимите 60 символов один RU-запрос отклонён после двух попыток.
Редакторская естественность и казахский язык пока не проверены человеком.
Принятие сервером не доказывает отсутствие всех галлюцинаций.

## Данные и воспроизводимость

В Notebook 48 уникальных языковых примеров (24 блюда): 32 ранее просмотренных
для разработки и 16 примеров восьми совершенно новых блюд для итоговой проверки.
Удалены 6 повторов в объединении итераций; состав не дополнялся. Есть аудит,
очистка, EDA, 8 графиков, признаки/наблюдаемые результаты и разделение по блюдам.
Веса LLM не обучались. Старый эксперимент сохранён в `../llm`.

Run All воспроизводит анализ без сети и ключа: ответы встроены в Notebook.
Изолированный запуск одного файла проверен локально; hosted Colab не проверялся.
Для повторения анализа из корня репозитория:

```sh
python -m pip install -r experiments/llm-v2/requirements.txt
python experiments/llm-v2/execute.py
python experiments/llm-v2/execute.py --portable
python experiments/llm-v2/build_documents.py
```

`results/freeze.json` содержит точный код и хеши до запросов к итоговым блюдам.
`results/*.jsonl` содержит каждый вход, промпт, сырой ответ, токены и время.
`dev.jsonl` — первый вариант разработки, `refined.jsonl` — уточнение перед
фиксацией; `tones.jsonl` — отдельная проверка тона, `final.jsonl` — holdout.
`browser.json` и `contract.json` — проверки сайта и явных ограничений API.
Промпты после просмотра final не менялись.

Новый live-прогон платный. Сначала сохраните старую папку `results` под другим
именем. Настройте `.env`, затем запускайте `node experiments/llm-v2/run.mjs`
с аргументами `dev`, `dev refined`, `tones`, `freeze`, `final` по порядку.
Для сайта: `npm run build`, затем `node experiments/llm-v2/browser.mjs` и
`node experiments/llm-v2/contract.mjs`. Новым ответам нужна новая редакторская
оценка; текущие выводы привязаны к текущим ответам, а не к названиям блюд.

## Лист рецензии

`analysis/human_review.csv` содержит исходные факты, полный ответ и пустые поля
для человека. `human_review_completed: false` сохранён явно. Рецензенту нужно
проверить состав и метод, язык, естественность и тон. Не заполняйте эти поля
автоматическими оценками под видом человеческих. Отмеченный пример хачапури
требует удаления утверждения о типе заведения перед использованием в меню.

Проверки кода: `npm test`, `npm run test:e2e`, `npm run build`,
`npm run format:check`. В последнем прогоне прошли 39 серверных и 9 браузерных тестов.
